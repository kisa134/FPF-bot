# FPF Studio — инструкция пользователя

**Адрес:** https://fpf-studio.onrender.com/

---

## Что это такое

FPF Studio — это пульт, на котором видно, **как ИИ думает под жёстким надзором правил**.

Обычный ИИ может соврать, забыть или сам себе противоречить. Здесь модель зажата в рамки FPF: она обязана оформлять мысли как строгие объекты (Контекст → Утверждение → Обоснование → Решение), и каждый её ход проверяется «привратником». Если модель ошиблась — система её отбивает, а не пропускает ошибку дальше. В студии этот процесс виден вживую.

---

## Быстрый старт (30 секунд)

1. Открой https://fpf-studio.onrender.com/
   *(если страница думает 30–50 сек — сервис «просыпался» после простоя, это нормально)*
2. В поле **Task** оставь пример или впиши свою задачу.
3. В «Brain» выбери **Demo** → нажми **▶ Run reasoning**.
4. Смотри: слева побегут карточки рассуждения, справа построится граф. Кликни узел графа — увидишь его содержимое.

---

## Три зоны экрана

### ◀ Слева — управление
- **Task** — задача для ИИ (что нужно решить/проанализировать).
- **Brain (model)** — кто «думает»:
  - **Demo** — офлайн-сценарий, без сети. Мгновенно. Для проверки интерфейса.
  - **WaveSpeed** — живая китайская модель (Qwen → DeepSeek → Kimi, с авто-фолбэком: если одна молчит, берётся следующая).
  - **Claude** — модель Anthropic (нужен свой ключ).
- **model id(s)** — необязательно. Можно указать конкретную модель или список через запятую.
- **▶ Run reasoning** — запуск. (Горячая клавиша: ⌘/Ctrl + Enter в поле задачи.)

### ▣ Центр — таймлайн рассуждения
Каждый ход модели — отдельная карточка, в реальном времени:
- 🟢 **Зелёный бейдж (✓)** — ход принят. Тип показан цветом (Контекст / Утверждение / Обоснование / Решение / Обязательство).
- 🔴 **Красная карточка (✕ или ↩)** — ход **отклонён привратником**, с причиной (напр. «ссылается на несуществующее утверждение» или «такой объект уже есть»). 

> **Красные карточки — это не баг, это главная фишка.** Видно, как модель пытается ошибиться, а система не даёт. Дальше модель получает причину отказа и исправляется.

### ▶ Справа — граф знаний + инспектор
- **Граф** — что модель построила: узлы (цвет = тип объекта), стрелки = связи:
  - `IN_CONTEXT` — объект принадлежит контексту;
  - `SUPPORTS` — обоснование подкрепляет утверждение;
  - `RELIES_ON` — решение опирается на утверждение;
  - `PROMISES` — обязательство к содержанию обещания.
- **Клик по узлу** → справа откроется карточка с полным FPF-объектом (все поля: формулировка, область применимости, срок свежести и т.д.). Закрыть — крестик.

### Внизу слева — статус
По завершении: **DONE** (задача доведена до решения) или **INCOMPLETE**, число ходов, и **кто ответил** (напр. `served by: qwen/qwen3-max`).

---

## Цвета типов

| Цвет | Тип | Что это |
|---|---|---|
| 🔵 Индиго | **Context** | Рамка смысла: в каком контексте всё происходит |
| 🔵 Голубой | **Claim** | Утверждение |
| 🟢 Зелёный | **Evidence** | Обоснование (со scope и сроком свежести) |
| 🟡 Янтарный | **Decision** | Решение (с альтернативами и правилом выбора) |
| 🟣 Фуксия | **Commitment** | Деонтическое обязательство |

## Примеры задач для пробы

- `Choose the primary datastore for a high-write telemetry service`
- `Should we buy, fine-tune, or build an agent stack for our product?`
- `Сравни три варианта архитектуры платежей и обоснуй выбор`
- `Оцени риски миграции монолита на микросервисы`

## Если что-то не так

| Симптом | Причина / что делать |
|---|---|
| Страница долго грузится при первом заходе | Free-хостинг «уснул» после простоя — будится 30–50 сек. Подожди. |
| Статус стал красным с текстом ошибки | Модель/сеть недоступна. На WaveSpeed сработает фолбэк на следующую модель; если все недоступны — попробуй Demo. |
| Граф пустой | Прогон не дошёл до записи объектов (см. причину в статусе/таймлайне). |
| WaveSpeed не отвечает | Возможно, кончились кредиты или сменился id модели — впиши актуальный id в поле model. |

---

## Важно про безопасность

Ключ WaveSpeed сейчас зашит в коде проекта (по запросу владельца). Это значит, что **любой может запускать прогоны за твой счёт**. Когда наиграешься — **перевыпусти ключ** в кабинете WaveSpeed и замени его в `v1/policy/_secret.py`.
